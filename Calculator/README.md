# Calculator
- Project1

## Description
This project is a simple Calculator developed using Python. It performs basic arithmetic operations based on user input. The project was created to practice Python fundamentals such as functions, conditional statements, loops, and user input handling.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- User-friendly menu
- Continuous calculations until the user exits

## Technologies Used
- Python
- Functions
- Conditional Statements
- Loops
- User Input

## How to Run
1. Open the Python file.
2. Run the program.
3. Select the required operation.
4. Enter the numbers.
5. View the calculated result.

## Learning Outcomes
Through this project, I learned:
- Creating functions
- Using conditional statements
- Working with loops
- Taking user input
- Building menu-driven applications
