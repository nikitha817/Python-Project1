# 1. Calculator

My very first actual program after learning about functions! This is a straightforward calculator that performs basic arithmetic operations.

- Calculates addition, subtraction, multiplication, and division for numbers.
- Allows continuous calculations until the user decides to quit.
- Uses a menu-driven interface for user-friendliness.

Skills developed: Functions, conditional statements, loops, handling user input, developing menu-driven applications.

This program functions as a data processing utility to organize and prepare student information before any analysis can take place.

What it does:

- Loads student details from different data sets.
- Structures the data efficiently.
- Organizes data in a ready-to-analyze format.

Skills developed: File handling, data organization, understanding datasets, modular functions.

# 3. Student Management System

A comprehensive system designed for managing all student records, including automated grade computations.

What it does:

- Enables users to add new student information (name and marks).
- Supports storage of data for multiple students.
- Automatically computes total and average marks for each student.
- Assigns grades (A, B, C, D, F) based on performance.
- Generates neatly formatted student reports.

Skills developed: Dictionaries, nested data structures, loops, string formatting, task automation.

---

# 4. Library Management System

A complete system for handling library operations, allowing users to add, borrow, and return books. Data is persistently saved to JSON files.

What it does:

- Allows users to perform actions such as adding, borrowing, returning, updating, and deleting books.
- Keeps track of borrowers and what they have checked out.
- Automatically calculates due dates for all borrowed items.
- Prevents duplicate entries of the same book.
- Persists all library data to JSON files.

Skills developed: JSON file handling, datetime module, exception handling, CRUD operations, data validation.

---

# 5. Number Guessing Game

An engaging game where the computer selects a random number, and the player gets six attempts to guess it.

What it does:

- Generates a random number between 1 and 100.
- Provides hints to guide the player throughout the 6 attempts.
- Records and reports the number of attempts taken to guess correctly.

Skills developed: random module, loops with iteration counting, exception handling, conditional logic.

---

# 6. Password Generator

A useful tool for generating strong and secure random passwords with a combination of letters, numbers, and special characters.

What it does:

- Takes the desired password length as input from the user.
- Creates a random password that matches the specified length and character requirements.
- Includes uppercase and lowercase letters, numbers, and punctuation.

Skills developed: string module, random.choice(), list comprehension, try-except blocks.

---

# 7. BMI Calculator

A practical application that calculates Body Mass Index (BMI) and classifies the result into various health categories.

What it does:

- Prompts the user to enter their weight and height.
- Calculates BMI using the standard formula: weight / (height * height).
- Categorizes the calculated BMI as underweight, normal, overweight, or obese.
- Incorporates input validation for accuracy.

Skills developed: Implementing formulas, using multiple functions, if-elif-else chains, exception handling.

---

# 8. Expense Tracker

An everyday tool for managing expenses. Users can add new entries, view a list of all recorded costs, and remove items, with an instant total calculation.

What it does:

- Allows users to record expenses along with their names and amounts.
- Displays a formatted list of all tracked expenses.
- Enables removal of specific expenses by their index.
- Calculates and shows the total spending immediately.

Skills developed: Lists of dictionaries, sum() with generator expressions, string formatting, input validation.

---

# 9. To-Do List

A task management system to help users keep track of what needs to be done.

What it does:

- Users can easily add new tasks to their list.
- Displays all current tasks with automatic numbering for clear referencing.
- Supports removing tasks by their number.
- Allows users to continue interacting with the list without restarting the program.

Skills developed: Using lists for data storage, enumerate() function, user-friendly indexing, input validation.

---

# 10. Weather App

A real-time application that retrieves live weather information from the OpenWeatherMap API.

What it does:

- Asks the user to enter a city name.
- Fetches up-to-the-minute weather data via an API call.
- Presents essential weather details like temperature, humidity, pressure, and wind speed.
- Handles various errors, such as incorrect city names or network connectivity issues.
- Can fetch weather for multiple cities through recursion.

Skills developed: HTTP requests, API integration, JSON parsing, recursion, error handling, handling KeyboardInterrupt.

---

# 11. Sales Analytics

A comprehensive business analytics tool leveraging the NumPy library to analyze sales figures across products and months.

What it does:

- Analyzes sales data for 5 distinct products over a 12-month period.
- Computes key business metrics like profit margins and growth rates.
- Identifies the best- and worst-performing products and months.
- Normalizes the data to facilitate comparison.
- Saves and loads data to/from JSON files.

Skills developed: NumPy arrays (multi-dimensional), statistical operations (sum, mean, max, min), axis-based operations, growth rate calculations, data normalization, understanding business logic.
