# Library Management System
- Project4

## Description
This project is a console-based Library Management System developed using Python. It helps manage books and borrowers by allowing users to add books, borrow books, return books, update stock, and delete books. The project stores data permanently using JSON files.

## Features
- Add books
- View all books
- Add borrowers
- Borrow books
- Return books
- Update book stock
- Delete books
- Prevent duplicate books
- Prevent duplicate borrowers
- Check book availability
- Store borrowed date and due date
- Save data using JSON files

## Technologies Used
- Python
- JSON
- File Handling
- Functions
- Dictionaries
- Lists
- Exception Handling
- Datetime Module

## How to Run
1. Run the Python file.
2. Choose an option from the menu.
3. Follow the instructions displayed on the screen.
4. All changes are automatically saved in JSON files.

## Learning Outcomes
This project helped me understand:
- File handling using JSON
- Data persistence
- Nested dictionaries and lists
- Exception handling
- Date and time operations
- Building menu-driven applications

## Future Improvements
