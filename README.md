# Python Learning Projects

Hi! I'm Nikitha, a second-year AI student at St. Ann's College for Women. This repo contains 11 Python projects I've built while learning programming. Each one represents a step forward in my journey from basic fundamentals to data analysis and real-world applications.

## 📋 My 11 Projects

### 1. **Calculator**

My first real project after learning about functions. A simple calculator that performs basic arithmetic operations.

**What it does:**
- Add, subtract, multiply, divide numbers
- Keep calculating until you exit
- Menu-driven interface

**Skills:** Functions, conditionals, loops, user input handling, menu-driven applications

---

### 2. **Student Performance Prediction**

Data processing system for organizing and preparing student information.

**What it does:**
- Load student information from datasets
- Organize data properly
- Structure data for analysis

**Skills:** File handling, data organization, datasets, modular functions

---

### 3. **Student Management System**

Comprehensive system for managing student records with automatic grade calculation.

**What it does:**
- Add student information (name, marks)
- Store multiple students
- Calculate total and average marks
- Automatically assign grades (A, B, C, D, F)
- Display formatted reports

**Skills:** Dictionaries, nested data structures, loops, string formatting, automation

---

### 4. **Library Management System** ⭐

Complete system where users can add books, borrow, return, and all data saves permanently using JSON.

**What it does:**
- Add, borrow, return, update, delete books
- Track borrowers and borrowed items
- Calculate due dates automatically
- Prevent duplicate entries
- Save everything to JSON files

**Skills:** JSON file handling, datetime module, exception handling, CRUD operations, data validation

---

### 5. **Number Guessing Game**

Interactive game where the computer picks a random number and you have 6 attempts to guess it.

**What it does:**
- Computer picks random number (1-100)
- You get 6 tries with hints
- Shows how many attempts it took to win

**Skills:** Random module, loops with tracking, exception handling, conditionals

---

### 6. **Password Generator**

Tool that creates random, secure passwords with letters, numbers, and special characters.

**What it does:**
- Takes desired password length
- Generates random password
- Uses uppercase, lowercase, numbers, punctuation

**Skills:** String module, random.choice(), list comprehension, try-except

---

### 7. **BMI Calculator**

Real-world application that calculates Body Mass Index and categorizes it.

**What it does:**
- Takes weight and height input
- Calculates BMI using formula: weight/(height²)
- Categorizes into health categories
- Validates user input

**Skills:** Formula implementation, multiple functions, if-elif-else chains, exception handling

---

### 8. **Expense Tracker**

Practical tool to track daily expenses, view them, delete specific ones, and calculate totals.

**What it does:**
- Add expenses with name and amount
- View all expenses in formatted output
- Delete specific expenses
- Calculate total spending instantly

**Skills:** Lists of dictionaries, sum() with generator expression, string formatting, input validation

---

### 9. **To-Do List**

Task management tool to keep track of what you need to do.

**What it does:**
- Add new tasks
- View all tasks with automatic numbering
- Remove tasks by number
- Repeat searches without restarting

**Skills:** Lists for storage, enumerate() function, user-friendly indexing, input validation

---

### 10. **Weather App** 🌍

Real-world weather application that fetches live weather data from OpenWeatherMap API.

**What it does:**
- Takes city name as input
- Fetches real-time weather data via API
- Displays temperature, humidity, pressure, wind speed
- Handles errors gracefully
- Search multiple cities via recursion

**Skills:** HTTP requests, API integration, JSON parsing, recursion, error handling, KeyboardInterrupt management

---

### 11. **Sales Analytics** 📊

Comprehensive business analytics tool using NumPy for analyzing sales data across products and months.

**What it does:**
- Analyze 5 products across 12 months
- Calculate profit margins and growth rates
- Find best/worst performing products and months
- Normalize data for comparison
- Save/load data with JSON persistence

**Skills:** NumPy arrays (multi-dimensional), statistical operations (sum, mean, max, min), axis operations, growth rate calculations, data normalization, business logic
