# Student Management System
- Project3

## Description
This is a Python-based Student Management System developed as part of my Python learning. It allows users to enter student details, calculate total and average marks, assign grades, and display student information in a formatted report.

## Features
- Add one or multiple students
- Store student details using dictionaries
- Calculate total marks
- Calculate average marks
- Assign grades automatically
- Display student reports in a formatted layout

## Technologies Used
- Python
- Functions
- Dictionaries
- Lists
- Loops
- Conditional Statements

## How to Run
1. Open the project in Python.
2. Run the Python file.
3. Enter student details when prompted.
4. View the generated student report.

## Learning Outcomes
Through this project, I learned:
- Creating and calling functions
- Using dictionaries and lists
- Writing loops
- Formatting output
- Organizing code into multiple functions
