# Student Performance Prediction
- Project2

## Description
This project is a Student Performance Prediction system developed using Python. The main objective of this project is to understand how student information can be collected, processed, and prepared for predicting academic performance. This project is being developed as part of my learning in Python and Artificial Intelligence.

## Features
- Load student dataset
- Read and organize student information
- Prepare data for prediction
- Modular code using functions
- Easy to extend with machine learning models

## Technologies Used
- Python
- Functions
- Conditional Statements
- Loops
- File Handling (Dataset)
- Basic Data Processing

## How to Run
1. Open the project in Python.
2. Load the required student dataset.
3. Run the program.
4. Follow the instructions displayed in the console.
